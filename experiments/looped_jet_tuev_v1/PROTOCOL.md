### Protocol B signal quality diagnostics

Use the same frozen real references and paired generated seeds for both models. Recover µV by multiplying loader-space samples by 100. Use 200 Hz sampling. For each class and channel, compute:

- PSD: Welch with Hann windows, segment 400, overlap 200, FFT length 400, and constant detrending. Measure mean absolute difference of the real and generated mean log10 PSD across 0.5–75 Hz.
- Band power: integrate the Welch PSD in [0.5, 4), [4, 8), [8, 13), [13, 30), and [30, 45] Hz. Compare log10 band power distributions with Wasserstein-1.
- Morphology: Wasserstein-1 on window-wise peak-to-peak, RMS, excess kurtosis, 95th-percentile absolute first difference, and zero-crossing rate after centering.
- Temporal: use nonoverlapping 200-sample RMS envelope blocks. Apply Wasserstein-1 to fitted envelope slopes and differences in the first and last block means and RMS.
- Spatial: compute window-wise 16 × 16 channel Pearson matrices and compare class-mean off-diagonal matrices by mean absolute error. Also compute Wasserstein-1 of the off-diagonal correlations.

As a complementary mechanism check, subtract each collection's class-, channel-, and time-specific mean waveform and compare residual off-diagonal correlation and covariance matrices. Estimate the mean from the full archived class, including evaluated rows. Match real and generated class counts to control the leading finite-sample centering asymmetry. Calculate temporal covariance within each window with denominator T−1 after subtracting the residual channel's temporal mean, then obtain Pearson correlation from that covariance. Average across valid windows and compare the class-mean matrices by MAE over the 120 unique upper-triangle pairs. Record sample and mean-estimation counts, native covariance matrices in µV², correlation matrices, and invalid channel and pair counts. Mark channels with sample residual variance ≤1e-12 µV² as nearconstant. This invalidates their Pearson correlations while finite zero covariance remains valid. Track counts and class validity independently for the two statistics. Undefined correlations remain undefined. If a pair has no valid estimate, leave that statistic's class discrepancy undefined. Its six-class macro requires every class to be defined. This is a descriptive check of linear temporal residual association. It supplements the frozen diagnostic family gate.

Report marginal discrepancies by named bipolar lead to assess channel exchangeability. For clustered train/validation resampling, keep directory IDs connected by identical EDF hashes in the same group.

Record each discrepancy in native units. Calibrate each primitive against its median real-vs-real discrepancy from 200 train-and-validation split-half replicates using seed 20261111. Each half contains whole connected components of directory IDs linked by identical EDF content. Freeze the sample count for each class at the minimum available in any half across the 200 predetermined partitions, capped at 512. Draw that many windows uniformly without replacement in each half. Flag the class as sparse if that count falls below 32 or any half contains fewer than five components supporting that class. Retain the prespecified partitions and report sparse classes without dropping them from the report.

Divide by the resulting scale with floor 1e-8. Average channels within each primitive, weight primitives within a family equally, then weight all six classes equally. Apply the same class counts to later comparisons that use the scales. Freeze 200 subsets using seed tuple `[20261111, 2, replicate, class, side]`, drawing independent real and generated positions within each class. Use the same archived positions across candidate and baseline. Report the arithmetic mean across subsets and retain each replicate. These overlapping subsets quantify sensitivity to the sampled windows. Independent training seeds and clustered uncertainty are separate analyses. Report full-set diagnostics separately. Preserve per-class results and report finite-value and undefined-statistic counts. All-zero generation fails.

For each of the five family scores, require the one-sided 95% upper confidence bound of candidate minus baseline to stay at or below the larger of 10% of the baseline discrepancy and 0.25 times the real-vs-real reference scale in the same units.
